SUBÜ BYS Downloader v2.0.1

INSTALL
1. Extract the ZIP.
2. Open chrome://extensions
3. Enable Developer mode.
4. Remove/disable older versions.
5. Click Load unpacked.
6. Select SUBU-BYS-Downloader-v2.0 (manifest.json is directly inside it).
7. Reload the open SUBÜ BYS tab once.

CORE FEATURES
- Clean redesigned popup.
- True inert OFF mode: no MutationObserver, polling, or recurring DOM scans.
- Download All / Choose Files / New Only.
- Computer / Google Drive / Both destination prompt.
- Optional remembered destination.
- Smart week-based filenames.
- Course folders locally and in Drive.
- PDF viewer, PowerPoint, Word, Excel, ZIP handling.
- Retry, auto-retry, skip, auto-skip, stop, pause-after-current.
- Progress overlay and toolbar badge.
- History + resume session.
- Drive folder browser, duplicate detection, replace/skip/keep-both.
- Export course document list to CSV.
