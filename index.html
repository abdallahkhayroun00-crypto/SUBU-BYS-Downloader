GETTING STARTED

Ready in four steps.

This is a manually installed Chrome extension, not a Chrome Web Store listing.

01

Download and extract

Download the GitHub source ZIP below, extract it, and find the folder containing manifest.json.

02

Open Chrome extensions

Enter chrome://extensions in Chrome's address bar and enable Developer mode.

03

Load the folder

Choose Load unpacked and select the extracted folder containing manifest.json. Disable any older copy first.

04

Open a BYS course

Refresh BYS, open a course's Dokümanlar tab, then use the extension. Connecting Google Drive is optional.

Keep the extracted folder after installation: Chrome loads the extension from that location. If the Google sign-in fails, the OAuth application may require the original extension ID or account access.

TRANSPARENCY

Privacy & download safety.

Review the permissions before installing or connecting your Google account.

What the extension can access

The extension accesses SUBÜ BYS course pages and requests browser download, storage, tab, identity, and notification permissions. Google Drive connection is optional, but its OAuth permission covers your full Google Drive account, not just one folder.

Authorize Drive only if you are comfortable with that access. You can review the exact permissions in the public manifest and revoke Google access in your account settings.

Download safety

Use the ZIP link on this page to get files directly from the project repository on GitHub. Extract and review the files before enabling Developer mode and loading the extension. A repository ZIP is source code, not a verified or signed browser-store release.

GOOD TO KNOW

Frequently asked questions.

Is this an official SUBÜ extension?

No. It is an independent student project, not an official SUBÜ service or university-endorsed tool.

Is it available in the Chrome Web Store?

The version linked here is installed manually from the GitHub source ZIP. There is no Chrome Web Store download link on this page.

Can I download without connecting Google Drive?

Yes. Choose Computer as the download destination. Google Drive authorization is optional and is only needed for Drive uploads.

Why does Google Drive request broad access?

Version 2.0.1 requests the full Google Drive OAuth scope. This allows more access than a single selected folder. Review the permissions before connecting; Google sign-in may also depend on the extension's OAuth configuration.

How do I update the extension?

Download the latest repository ZIP, extract it to a stable folder, disable or remove the old extension, and load the updated folder in Chrome. Review the source and version first.
